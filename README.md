# IrisVisionAI

## AI Data Classification Project

This project demonstrates a fundamental supervised learning task: building a basic classification model using a small dataset, aligned with the guidelines from **"Artificial intelligence P2.pdf"**.

---

## Objective

- Load and understand a dataset.
- Split data into training and testing sets.
- Apply a simple classification algorithm.
- Evaluate the model's performance.

---

## Dataset

The dataset used in this project is the Iris dataset, a classic in machine learning, containing measurements of iris flowers classified into three species.

---

## Requirements

- Python 3.x
- scikit-learn
- pandas
- numpy

---

## Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/your-username/iris-classification.git
```

2. Navigate into the directory:
```bash
cd iris-classification
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

*(Ensure you create a `requirements.txt` file with the necessary libraries if not already present)*:
```
scikit-learn
pandas
numpy
```

---

## Usage

Run the main Python script:
```bash
python iris_classification.py
```

This script will:
- Load the Iris dataset.
- Display initial dataset information.
- Split data into training and testing sets.
- Train a Decision Tree classifier.
- Predict labels on the test set.
- Evaluate model accuracy and display detailed metrics.

---

## Project Workflow

1. **Data Loading**: Import and review the dataset.
2. **Data Understanding**: Examine data structure and feature distributions.
3. **Data Preparation**: Separate features and labels.
4. **Data Splitting**: Use train-test split for validation.
5. **Model Training**: Apply a simple classifier (Decision Tree).
6. **Prediction and Evaluation**: Assess performance using accuracy, classification report, and confusion matrix.

---

## Notes

- Focus on mastering the supervised learning pipeline.
- Experiment with different algorithms or hyperparameters for better accuracy.
- Use low accuracy scores as learning opportunities to refine your model.
